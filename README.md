# AIM:
To study the problem statement and SRS document, and draw all the UML diagrams for the Student Enrollment System.
# SRS (Procedure):
## Step 1: Problem Identification
The main problem is the need for a fast, secure, and automated system that allows students to register for courses, check course availability, enroll in courses, and manage their enrollment details efficiently.
## Step 2: Requirement Analysis
Identify user needs:Student,Admin,Faculty,Enrollment Officer Define functional requirements:Student registration,Course availability check,Course selection,Course enrollment,Enrollment cancellation,Student record management,Course and faculty management Define non-functional requirements:Speed,Security,Reliability,Usability,Data integrity Step 3: System Design Draw UML diagrams to represent the Student Enrollment System: Use Case Diagram Class Diagram Activity Diagram Sequence Diagram Communication Diagram Package Diagram Design the database with tables for:Student,Admin,Faculty,Enrollment Officer,Course EnrollmentDepartment
